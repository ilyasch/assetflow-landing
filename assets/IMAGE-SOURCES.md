# Generated site photography

This raster image was generated for the AssetFlow landing website on 21 October 2026 with OpenAI image generation. It is illustrative marketing content, not a product screenshot or evidence about a customer's vehicle.

- `vehicle-photo.jpg`: editorial photograph of an unbranded dark green compact vehicle outside a contemporary home. Used inside the illustrative ownership interface.

The JPEG fallback is resized to 1000 × 750 with macOS `sips` JPEG quality 40
(123,500 bytes), preserving the original framing. Responsive WebP variants are
generated from the original 1448 × 1086 JPEG at widths 320, 360, 480, 560, 668,
800 and 1000 using `sharp-cli@6.1.0`, WebP quality 35, with no cropping. The
800-pixel variant fills the gap between 668 and 1000 pixels. This is an optional
asset-authoring tool; packaging and the published website need no npm dependency.

The original generated PNG is preserved in the local Codex generated-images folder. This JPEG is an optimized copy used by the static site. Existing AssetFlow logos and social preview artwork are unchanged.
